# Lithuanian Economy Dashboard

Live site: https://stefangirstmair.github.io/lt-economy-dashboard/

Growth, labour market and inflation in Lithuania, with Latvia, Estonia and the euro area, including a
supply/demand decomposition of HICP inflation. Data come from Eurostat and Statistics Lithuania and are
refreshed automatically every week.

A personal project by [Stefan Girstmair](https://stefangirstmair.github.io/). It is not an official publication
of Lietuvos bankas or any other institution; the views and any errors are my own.

This repository holds only the built static site. It is overwritten by an automated weekly job, so changes made
here directly will be lost.
